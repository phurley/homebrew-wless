# homebrew-wless

Homebrew tap for [wless](https://github.com/phurley/wless), a word-wrapping, auto-following terminal pager.

## Install

```sh
brew install phurley/wless/wless
```

or tap first:

```sh
brew tap phurley/wless
brew install wless
```

The formula tracks [wless releases](https://github.com/phurley/wless/releases) and is updated automatically by wless's release workflow whenever a new version is tagged.
